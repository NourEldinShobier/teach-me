# Language lessons

## Items

- Nouns always with article, gender colour and plural: `<span class="g-m">der Hund</span>`, pl. `die Hunde`. Colours: masculine blue `.g-m`, feminine red `.g-f`, neuter green `.g-n`. Colour the article only, or the whole noun phrase; be consistent in a workspace.
- Verbs with the forms the learner needs at their level (A1: present; A2: + Perfekt with haben/sein; B1: + Präteritum of common verbs). Mark separable prefixes (`an|rufen`).
- Each item gets an example sentence at the learner's level, with 🔊 (`<span data-say="de-DE">…</span>`).
- Group by a real situation (at the bakery, calling the doctor, a stand-up at work), not by word class.

## Drills that work in the page

- Cloze cards: `"front": "Ich fahre {{c1::mit dem}} Bus."` Test one thing per blank.
- Gender drills as `quiz`: options `der` / `die` / `das` (equal length by design), `why` gives the rule or the memory hook (e.g. `-ung` → die).
- Case drills as `quiz` with a short scenario sentence; options differ only in the tested form.
- Dialogue: a `.tm-table` with speaker, line (`data-say`), translation in a muted column the learner can hide by reading only the left side.
- Production and free writing happen in chat, not in the page. The page ends with 3 prompts in the `ask` box, e.g. "Correct my 3 sentences using *weil*".

## Audio

The runtime uses the browser's Web Speech API on click only. Voice quality depends on the system: on Windows, Edge's online "Natural" voices sound best; Chrome uses installed voices (add German in Windows Settings → Time & language → Speech). The page shows a notice when no German voice exists. Shift+click plays slowly.

## Levels (CEFR, short)

A1 survive simple exchanges · A2 routine tasks, past tense · B1 handle travel and work situations, give reasons (*weil*, *dass*) · B2 discuss abstract topics, subjunctive (*Konjunktiv II*) · C1 flexible, nuanced, idioms.
