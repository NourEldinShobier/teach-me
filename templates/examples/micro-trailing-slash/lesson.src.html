/docs vs /docs/

The big idea

The browser treats everything after the last slash as a file name, so the slash decides which folder relative links start from.

You will be able to: predict where ./logo.svg loads from, and why servers redirect /docs to /docs/.

A URL path looks like a file path. The browser follows one rule when it resolves a relative link: drop everything after the last / of the current page, then append the link.

So why does the server redirect?

On disk, docs is a folder holding index.html. If the server returned that file at /docs, every relative link inside it would point one folder too high. So Apache and nginx answer /docs with a 301 redirect to /docs/ first.
