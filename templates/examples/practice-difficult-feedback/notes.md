# practice-difficult-feedback

Format: practice. Topic: giving hard feedback with SBI (Center for Creative Leadership).

- Sources fetched: CCL article "Use Situation-Behavior-Impact (SBI) to close the gap between intent and impact" (definitions of S, B, I and the Intent step); CCL "Feedback That Works" 2nd ed. promo PDF (publisher summary only, full text not read).
- Invented for the lesson: Maya/Dev and Sam scenarios, the five Behavior wordings, the tension numbers. The lesson says so in the page and the footer.
- Model: delta = .3*judgment + .2*sting - .1*specificity - .25*curiosity - .12*warmth, clamped .05..1, start 65%. `tension(i, p)` drives the scene (faces, sweat drop, aura, needle, chips, hint); the sim reuses `delta` and `tEnd(1)`.
- Flow: predict (opening line) -> reveal scene -> mapping table -> sim (five wordings) -> 3 scenario quizzes (Behavior, Impact, defensive reply) -> principle cards -> explain-back -> "try it this week" callout -> ask/save -> sources.
