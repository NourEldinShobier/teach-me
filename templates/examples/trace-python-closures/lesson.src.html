Why every lambda prints 2

The big idea

A function stores the name i, not its value. It reads the name when called.

You will be able to: predict what lambdas built in a loop return, and fix them with a default argument.

Python looks up a variable that a function does not define itself at the moment the function runs. Lambdas made in a loop all share the loop's one variable.

One name, many readers

Each lambda holds code that says "return i". It does not hold a number. Change the settings and watch which cell each lambda reads.

The fix, traced

The default i=i is evaluated once, when the lambda is created. The value is then stored inside the function.
